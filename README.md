# 光润通 · 客户自动查找与筛选工具

依据《工作流（含用户画像及查找方式）— 修订版 V3.1》实现的自动化流水线：

**查找客户 → 筛选客户 → 输出客户**

- 候选公司由系统自动查找并累积，无需手动提供
- 自动标准化去重（去重库A + 历史去重库B + 本批重复）
- 自动业务线分类、自动生成备注、自动输出规范表格
- 去重库**首次输入、自动记忆、可导出**，换设备可迁移，朋友也能用

## 使用方式（在线版，推荐）

打开 `https://qjbywx.github.io/kehu-tool-site/`：

1. **首次使用**：上传《查找汇总表格.xlsx》（或导出的 `去重库A JSON`），自动记忆，之后无需重复上传。
2. 点 **“一键获取最新候选”**：自动拉取系统每日查找累积的候选池，完成去重、业务线分类、备注生成。
3. 点 **“全部 AI 验证”**（或每家公司的“AI 验证”按钮）自动完成五项校验，验证过的公司按钮会变为“重新验证”，可随时重跑。
4. 点 **“生成输出”**，一键复制或下载。输出自动归档历史、累积去重库B，下次自动排重。

### AI 验证说明

- **内置自动初筛（免配置）**：根据候选池已有的地址/经营范围/来源证据自动判定②③④⑤项，无法确认的项（主要是①工商存续状态）会明确标注原因。
- **真 AI 核验（推荐）**：在“AI 验证设置”里填入兼容 OpenAI 格式的接口地址、Key、模型（OpenAI、DeepSeek 等均可），五项校验由 AI 逐项给出通过/不通过及原因，自动勾选。Key 只保存在本机浏览器，随备份导出。
- 如需①存续状态的权威核验，可后续接入天眼查/企查查开放 API。

## 使用方式（本地，无需网络）

双击 `index.html`：

- 去重库A：粘贴公司名或上传 JSON/TXT（离线时 Excel 解析组件无法加载，请用 `build_dedup.py` 先生成 JSON）；
- 候选：直接点 **“一键获取最新候选”** 即可（工具会自动读取同目录的 `candidates.js`，无需手动导入）；
  请保持 `index.html`、`app.js`、`candidates.js` 在同一文件夹。若文件缺失，也可用 **“导入候选JSON”** 手动选择。

## 自动查找是怎么工作的

- GitHub Actions 每天北京时间 08:00 自动运行 `search/search.py`（也可在 Actions 页面手动点击运行）。
- 引擎按“工作流关键词 × 京津冀”搜索公开网页，提取真实公司名，过滤区域/实体关键词，自动分类业务线，结果累积写入 `candidates.json`。
- 免 key 模式使用 DuckDuckGo（单次查询量受限，按天轮换关键词）；**推荐配置 Bing Web Search API**（Azure 免费档每月 1000 次）：

```bash
# 1. Azure 创建 Bing Search 资源，复制 Key
# 2. GitHub 仓库 → Settings → Secrets and variables → Actions → New repository secret
#    Name: BING_API_KEY    Value: 粘贴 Key
```

配置后自动查找质量与数量都会明显提升，无需改任何代码。

## 去重库维护

```bash
python build_dedup.py "F:/桌面/查找汇总表格.xlsx"
```

生成 `dedup_a.json`，在网页“上传 Excel/JSON/TXT 载入去重库A”上传即可。该文件已加入 `.gitignore`，**不会进入仓库**。

换设备 / 给朋友：用“导出去重库A”或“导出数据备份”得到 JSON，对方“导入”即可。

## 数据与隐私

- 去重库A/B、候选、历史输出等**全部只保存在各浏览器本地（localStorage）**，不上传任何服务器。
- 仓库与网页中不含任何客户名单，公开部署也安全。
- 定期“导出数据备份”，防止清理浏览器缓存导致数据丢失。

## 目录结构

```text
index.html / app.js       网页工具（前端）
search/search.py          自动查找引擎
candidates.json           自动查找累积的候选池（公开、不含客户数据）
build_dedup.py            把 Excel 导出为去重库A JSON
.github/workflows/
  auto-find.yml           每日自动查找 + 部署
  deploy-pages.yml        代码推送后自动部署
tests/                    单元测试与浏览器端到端检查
```
